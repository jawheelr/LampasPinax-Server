# LampasPinax HD asset package

All PNG assets are rendered from the vector `branding/lampaspinax-icon.svg` master rather than enlarged from a small raster.

Apple TV assets include native 1x and independently rendered 2x files for large and small layered icons, standard and wide Top Shelf images, a 1920x1080 home background, and a 3840x2160 home background. Cross-platform assets include transparent symbols through 4096x4096, Windows ICO, macOS ICNS, Linux PNGs, Raspberry Pi PNGs, and 1920x1080 splash images.
